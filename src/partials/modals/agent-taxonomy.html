SYSTEM ARCHITECTURE SPECIFICATION

AGENT TAXONOMY & WORKFLOW STAGES

The workflow moves software delivery from manual ticket juggling to an orchestrated multi-agent process. A human sets the goal, specialized agents execute each stage, and a human approves the result.

STAGE 01 : CONCEPT

Requirements & Architect agents: Turn a human goal into stories, acceptance criteria, system design, and atomic tasks, informed by codebase context.

STAGE 02 : PARALLEL BUILD

Orchestrator & developer agents: The orchestrator dispatches atomic tasks to backend, frontend, and domain agents working in parallel, then integrates the results.

STAGE 03 : VALIDATION

PR & QA agents: Assemble the changeset, run functional and regression tests, review security and quality, and consolidate the evidence into one PR dossier.

Human Touchpoints
  • Goal definition : A human defines scope boundaries and guardrails before any agent starts.
  • Advisor on demand : Agents escalate trade-offs, specification gaps, and merge conflicts to a human advisor.
  • Final gate : A human accepts the PR dossier and approves the merge; rework flows back to the orchestrator.
